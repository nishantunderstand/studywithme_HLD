What is Protocols ?
A protocol is a set of rules that defines how two systems communicate, including the format of messages, how they are exchanged, and how errors are handled.

HTTP 
HTTP : Hyper Text Transfer Protocols
Who Invented : 
- Tim Berner Lee (Created)
- Roy Fielding (Contributed)
HTTP is an application-layer protocol used for communication between clients (such as browsers or applications) and servers.


Types of HTTP 

- HTTP/1.0 Basic request-response
- HTTP/1.1 Persistent connections
- HTTP/2 Multiplexing
- HTTP/3 QUIC over UDP
