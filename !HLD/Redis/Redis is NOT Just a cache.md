"Redis is an in-memory data store — far more than just a cache. Five real use cases:  
  
Caching — frequently accessed data stored in memory, database never touched on repeat requests. Instagram, Amazon, Netflix all use this.  
  
Session Storage — login sessions stored in Redis for millisecond validation on every request. Database-backed sessions would bottleneck at scale.  
  
Rate Limiting — Redis maintains per-user request counters. Limit exceeded — request rejected immediately. Protects APIs from abuse and DDoS without touching the application server.  
  
Pub/Sub Real-Time Messaging — one service publishes, all subscribers receive instantly. Used for live notifications, chat, stock price updates, online presence.  
  
Leaderboards and Counters using Sorted Sets — maintains ordered rankings automatically in O(log n) time. Used in gaming, fantasy sports, coding contests.  
  
One in-memory tool. Five distinct infrastructure problems. Sub-millisecond latency across all of them."
