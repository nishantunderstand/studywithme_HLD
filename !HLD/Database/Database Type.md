Revise THESE Database Interview Topics!  
  
The database you choose depends on 2 things:  
→ What your data looks like  
→ How you want to query it  
  
Here are the 5 types that actually matter 👇  
  
1. SQL (Structured + Consistent)  
Tables, rows, transactions  
→ Best for user data, payments, anything that must be correct  
  
2. NoSQL (Flexible + Scalable)  
Documents, key-value, massive scale  
→ Best for feeds, chats, logs, large unstructured data  
  
3. Graph DB (Relationships)  
Nodes + edges  
→ Best for recommendations, “people you may know”, connections  
  
4. Time-Series DB (Data over time)  
Timestamped events  
→ Best for analytics, monitoring, system metrics  
  
5. Vector DB (AI-native)  
Embeddings + similarity search  
→ Best for recommendations, semantic search, RAG systems  
  
Different databases solve different problems.
