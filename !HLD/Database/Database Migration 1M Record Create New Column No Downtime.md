Interviewer: “You have a table with 1 million+ records, and a new record is inserted every 10 seconds. How would you add a new column without any downtime?”  
  
This is one of those Senior Backend/System Design interview questions that tests whether you understand how databases behave in production.  
  
In this reel, I explain the 3-stage zero-downtime migration strategy:  
✅ Add the column with NULL values  
✅ Deploy code changes for new records  
✅ Backfill existing data in batches without impacting live users  
  
If you want to crack Backend or System Design interviews, this is a concept you should know.
