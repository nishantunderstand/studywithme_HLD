🧑‍💻 Database indexing speeds up data retrieval by using a data structure like B-Tree to locate rows without scanning the entire table — reducing search complexity from O(n) to O(log n). Indexes improve performance for WHERE, JOIN, ORDER BY, and GROUP BY queries. Primary indexes are automatically created on primary keys. Secondary indexes are manually created on frequently searched columns like email or username. Composite indexes cover multiple columns with left-to-right matching order. The trade-off is that indexes improve read performance but increase write overhead because every INSERT, UPDATE, and DELETE must also update the index. Clustered indexes physically sort data in index order while non-clustered indexes maintain a separate pointer structure.
