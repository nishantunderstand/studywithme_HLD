## Cache Line Organization 🤔🤔🤔 
The cache lines do not have a fixed address, allowing the cache to store data from various locations in memory.

Types
1. Fully Associated
2. Direct Mapped
3. Self Associated

---
In CPU architecture:
- L1 = Smallest and fastest CPU cache.
- L2 = Larger, usually slower cache.
- L3 = Larger shared CPU cache.
